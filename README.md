# Project ROMANA — The Dr. Eline Oslo Saga

A narrative site built for the NASA "Mars to Table" Challenge, following Dr. Eline Oslo — a
Stavanger-based food scientist and engineer — as she builds a system that treats fermentation
(coffee, beer) as high-fidelity biological telemetry, using the same observability discipline
that keeps a hydrogen UAV airborne.

**Mission:** Resilience-as-a-Service. Uncertainty is a feature to design for, not a bug to
optimize away.

## Structure

- `index.html` — the site
- `style.css` — visual system (Munch-inspired: swirling fjord sky, brush-stroke dividers, warm/rust palette)
- `script.js` — the Flight/Ferment console toggle and ambient sky animation
- `assets/` — images and icons

## Local preview

Just open `index.html` in a browser — no build step, no dependencies.

## Deploying to GitHub Pages

1. Push to `main`
2. Repo → **Settings → Pages → Source: Deploy from branch → main / (root)**
3. Site publishes at `https://lightmache.github.io/MarstoTable/`
